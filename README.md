## Development

This is a static HTML, CSS, and JavaScript website with no dependencies or build step.

```sh
python3 -m http.server 8080
```

Open http://localhost:8080.

- `index.html`: homepage, research, projects, work experience, background, and contact
- `others.html`: interests and personal notes
- `404.html`: fallback page and redirects from the previous portfolio address
- `cv.html`: academic CV with print and Save as PDF support
- `styles.css`: responsive layout and print styles
- `script.js`: copyright year and CV print action
- `favicon.svg`: site icon

Commit changes to `main` to publish them through GitHub Pages.
